# Teenlancer

Unified Teenlancer platform monorepo for the web, Android, iOS, backend, and shared platform resources.

## Repository structure

- `apps/web` — Web application
- `apps/android` — Native Android application
- `apps/ios` — Native iOS application
- `backend` — Shared platform backend
- `shared` — Cross-platform contracts, models, schemas, constants, assets, design tokens, and documentation

## Migration principle

Existing `student-marketplace` and `skilllaunch-android` repositories remain preserved while their contents are migrated and verified in this repository incrementally.
